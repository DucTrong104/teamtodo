# Project Brief – TeamTodo

## 1. Project Overview
Xây dựng ứng dụng quản lý công việc cá nhân bằng Python.

## 2. Project Objectives
- Thực hành Git và GitHub trong môi trường làm việc nhóm.
- Rèn luyện kỹ năng phân chia công việc.
- Thực hành quy trình Pull Request và Code Review.
- Xây dựng một ứng dụng Python hoàn chỉnh.

## 3. Main Features
- Create Task
- View Task
- Update Task
- Delete Task
- Complete Task
- Search Task
- Task Statistics
- JSON Data Storage

## 4. Team Size
4 members.

## 5. Duration
4 weeks.

## 6. Definition of Done
- Chức năng hoạt động đúng.
- Code được kiểm thử.
- Có Pull Request và được review.
- Đã merge vào main.
- Tài liệu được cập nhật.
